These tables are the slot props of `AbAppLayout`, `AbMainLayout` and `AbAsideLayout`, and the page-provider API next to them (`useAbPage`). A heading marked server is that package's server entry. It declares the same members as the client entry, so the members are not repeated. `getAbMainScroller` is not a core export. It lives on [Scroll spy](/docs/packages/hooks/scroll-spy), from `ab-nextjs-components/ab-toc`.

## Not a public import

These names are not exported from a package entry. There is no supported import path.

- `toAbSlot` — Used by the layout implementations. ab-nextjs-core/ab-page-provider does not export it, and no exports entry points at its source file.
- `AbScrollRegistrar` — Used by the server layouts. ab-nextjs-core/ab-page-provider does not export it, and no exports entry points at its source file.
- `AbScrollRegistrarProps` — Props of AbScrollRegistrar. ab-nextjs-core/ab-page-provider does not export it, and no exports entry points at its source file.
- `AbMainBarHeight` — Rendered inside the main layout. ab-nextjs-core/ab-main-layout does not export it, and no exports entry points at its source file.
