## Overview

**ab-nextjs-components** is the UI. Buttons, chips, links, code blocks, tabs, drawers and the app bar all live here, styled by [Theme](/docs/packages/theme) and framed by [Core](/docs/packages/core). Icons are drawn with `AbIcon`, which reads artwork from [Icons](/docs/packages/icons).

Many pieces have a server twin under `ab-nextjs-components/server/` (`AbButton`, `AbIcon`, `AbLogo`, `AbSidebar`, `AbNavbar`). Use the server file when the element does not need state.

`AbButton` types in this release are `contained`, `filled`, `outlined`, `text` and `secondary`. Sizes are `md` (the default) and `lg`. There is no separate tonal type and no small / medium / large scale yet. A props table for each component is not part of this page.

## Install

```bash
pnpm add ab-nextjs-components
```

```css title="app/globals.css"
@import 'ab-nextjs-theme/styles.css';
@import 'ab-nextjs-components/styles.css';
```

Import the theme first. See [Installation](/docs/installation).

## Usage

```tsx title="app/save.tsx"
import AbButton from 'ab-nextjs-components/ab-button';

export function SaveBar() {
  return (
    <>
      <AbButton label="Save" type="contained" />
      <AbButton label="Cancel" type="outlined" />
      <AbButton label="Learn more" type="text" />
    </>
  );
}
```

`AbLink` is the locale-aware link. Wrap the tree in `AbLinkProvider` when links should pick up the locale prefix from [i18n](/docs/packages/i18n).

Docs pages are built from packaged pieces only: `AbBreadcrumbs`, `AbChip`, `AbCodeBlock`, `AbCallout`, `AbContentTabs`, `AbDocPager`, `AbPreviewCode` and `AbToc`. The shell adds `AbAppBar`, `AbSidebar`, `AbNavbar`, `AbMobileHeader`, `AbNavDrawer`, `AbTocDrawer`, `AbSettingsDrawer` and `AbSearchDrawer`.

## What it ships

The catalog is the package root `supportedComponents` list. Highlights for a docs app:

- Actions: `AbButton`, `AbIconButton`, `AbLink`
- Status: `AbChip`, `AbPill`, `AbKbd`, `AbCallout`, `AbInfo`, `AbBadge`
- Docs: `AbCodeBlock`, `AbContentTabs`, `AbDocPager`, `AbPreviewCode`, `AbDemoBox`, `AbDemoCode`, `AbToc`, `AbBreadcrumbs`, `AbInstallSnippet`
- Shell: `AbAppBar`, `AbSidebar`, `AbNavbar`, `AbMobileHeader`, `AbLogo`, `AbSearchTrigger`
- Drawers: `AbDrawer`, `AbNavDrawer`, `AbTocDrawer`, `AbBottomDrawer`, `AbSettingsDrawer`, `AbSearchDrawer`, `AbConfirmDrawer`

`AbInstallSnippet` is the four-manager install block (pnpm, npm, yarn, bun) used on the home page. These docs use `AbContentTabs` for the same commands, which is the MDX tabs element.

`AbPropsTable` is not in this release, so this overview does not invent a props grid.
