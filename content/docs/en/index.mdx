## What is AbElements?

AbElements is a family of eight `ab-nextjs-*` packages. Each one does one job: layouts, components, theme tokens,
icons, fonts, animations, hooks and i18n. You install only what you need.

## Why packages?

- Every package is typed and tree-shakable.
- Server Components first: client code only where interaction needs it.
- One design language across every app that uses them.

### Who is it for?

Teams that want a documentation-quality shell (sidebar, outline, search) without a docs framework.
