## What is AbElements?

AbElements is the docs site for a family of eight `ab-nextjs-*` packages, and it is built with those same packages. Each package does one job. You install only the ones a screen needs.

Every page shares one warm design: a light page and a dark page, with a bronze accent for links and actions. Sage shows up only as a small status mark, such as a stable chip. The exact colours and typefaces are on the [Theme](/docs/packages/theme) page.

Abraham Ukachi writes the packages and this site. The packages are MIT licensed.

## The eight packages

- [Fonts](/docs/packages/fonts) — self-hosted faces for titles, body text and code.
- [Icons](/docs/packages/icons) — AbIcons as SVG and CSS, outlined and filled.
- [Animations](/docs/packages/animations) — keyframes and class names that respect reduced motion.
- [Theme](/docs/packages/theme) — design tokens, light and dark, and the prose styles these pages use.
- [Hooks](/docs/packages/hooks) — theme, media, clipboard, storage and the outline's scroll spy.
- [Core](/docs/packages/core) — the screen, the main pane and the aside. The page itself does not scroll.
- [Components](/docs/packages/components) — buttons, chips, code blocks, drawers and the rest of the UI.
- [i18n](/docs/packages/i18n) — English, French, Spanish and Russian. English lives at `/`; the others are prefixed.

## How a docs page is put together

The shell is [Core](/docs/packages/core). Below 768px the sidebar is a left drawer and **On this page** is a right drawer. From 1180px the aside sits beside the article. Headings in the article become the outline. The previous and next links follow the sidebar order.

Live previews, where a page has them, render the real package components. The **Code** tab is that same source, highlighted when the site is built. There is no separate sample to drift out of date.
